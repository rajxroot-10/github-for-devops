# iOS build

Create/open an Xcode iOS App project named `ShivshambhoSelfDrive`, bundle identifier `com.shivshambho.selfdrive`, then add `ShivshambhoSelfDrive/AppDelegate.swift`, `SceneDelegate.swift`, `Info.plist`, and `index.html` to the target. Select a signing team and build/archive.

A signed `.ipa` cannot be produced without Apple/Xcode signing credentials.
